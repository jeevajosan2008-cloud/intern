# Data Science Internship - Task 1: EDA on Titanic

Exploratory Data Analysis on the Titanic dataset using **Pandas** and **NumPy**.

## What this covers
- DataFrame operations (`head`, `info`, `describe`)
- Handling missing values (Age, Embarked, Cabin)
- Removing duplicates
- Feature engineering (FamilySize, AgeGroup)
- Grouping and aggregation analysis (survival by sex, class, age, port)

## Files
| File | Description |
|------|-------------|
| `Task1_Titanic_EDA.ipynb` | Main analysis notebook |
| `titanic_cleaned.csv` | Cleaned dataset (generated by the notebook) |

## How to run
1. Open the notebook in Google Colab or Jupyter.
2. Run all cells (`Runtime > Run all`).

## Key findings
- Overall survival rate was about 38%.
- Women and 1st-class passengers had much higher survival rates.
- Children survived more often than other age groups.

## Tools
Python, Pandas, NumPy, Google Colab
